# True distance and true size are two separate toggles, both off by default

Distances and sizes are distorted by default so the scene stays readable. When a distortion is active, the scene says so in plain words inside the scene itself.

The two scales are independent on purpose: a scene can show true distances with enlarged bodies, or the reverse, and the child sees which distortion is in play. Rejected: one shared "realistic" switch, which hides which of the two scales is doing the exaggerating — and one honest scale everywhere, which makes the Sun a dot and the Earth invisible.

True distance is for looking, not for navigating: at a zoom where the Sun fills 300 px of a phone screen, the Earth is 3 px wide.
