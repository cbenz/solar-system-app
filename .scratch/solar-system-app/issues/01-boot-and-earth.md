# 01: Boot and Earth

**What to build:** The app has a URL. It opens on a rotatable, zoomable Earth rendered in 3D with a decorative starfield behind it, and it redeploys itself from the repository with no build step anyone has to remember.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] The build output is static files and runs with no server
- [ ] Opening the app shows the Earth, and nothing else asking for attention
- [ ] One finger drags to rotate; two fingers pinch to zoom
- [ ] The Earth carries a simple texture, and the half turned away from the light is visibly dark
- [ ] The stars are decorative and the scene holds a stable frame rate on a mid-range phone
- [ ] A push to the default branch produces a new deployment
